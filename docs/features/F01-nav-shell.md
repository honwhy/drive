# F01 入口、导航与对局管理（NAV）

> 需求来源：`requirement.md` §3.1、§4.1 ｜ 技术约定：`AGENTS.md` ｜ 状态：已实现待验证（见 [PROGRESS](PROGRESS.md)）

## 1. 目标

提供从启动到结算的完整页面流转：主菜单、关卡选择、策略选择、关卡说明、倒计时、暂停、重开、退出、结算、帮助与关于。玩家不登录、不联网也能走完全流程。

## 2. 需求范围

NAV-01 主菜单、NAV-02 关卡选择、NAV-03 策略选择、NAV-04 开局说明、NAV-05 倒计时、NAV-06 暂停恢复、NAV-07 重开退出、NAV-08 结束条件、NAV-09 帮助、NAV-10 关于。

## 3. 页面与状态

| 屏幕     | 进入条件              | 关键内容                                     | 退出动作                   |
| -------- | --------------------- | -------------------------------------------- | -------------------------- |
| 主菜单   | 启动 / 从任意页面返回 | 开始游戏、关卡选择、智驾策略、操作说明、设置 | 进入对应页面               |
| 关卡选择 | 主菜单                | 7 张卡片：名称、目标、最佳、星级、锁定       | 选关 → 策略（第 1 关跳过） |
| 策略选择 | 已选第 2～7 关        | 三种策略参数与说明                           | 确认 → 关卡说明            |
| 关卡说明 | 已选策略              | 目标、新概念、失败条件、开始/跳过            | 开始 → 倒计时              |
| 驾驶中   | 倒计时结束            | Canvas 世界 + HUD                            | 暂停 / 结束 / 主动退出     |
| 暂停     | 驾驶中                | 继续、重开、说明、设置、退出                 | 继续 → 1 s 倒计时          |
| 结算     | 终点/碰撞/安全停车    | 报告、重玩、下一关、返回                     | 对应跳转                   |

状态机约束：`menu → levelSelect → policySelect → briefing → countdown → driving ⇄ paused → result`；主动退出直接回 `menu` 且不计成绩。

## 4. 规则要点

- 倒计时 3-2-1 期间世界冻结、计时不启动；恢复前 1 s 倒计时。
- 暂停期间物理、指标、计时全部停止；切后台自动暂停（ENV-03）。
- 重开清空本局指标与场景，不改变已保存进度。
- 结算页“下一关”仅在通过且存在下一关时可用。
- 页面刷新不恢复进行中对局（SAV-03）。

## 5. 模块与接口

```ts
type Screen =
  | 'menu'
  | 'levelSelect'
  | 'policySelect'
  | 'briefing'
  | 'countdown'
  | 'driving'
  | 'paused'
  | 'result';
interface ScreenRouter {
  go(screen: Screen, payload?: unknown): void;
  readonly current: Screen;
}
```

- `src/app/router.ts`：屏幕切换与返回栈；不持有游戏状态。
- `src/app/app.ts`：装配屏幕、单例循环、HUD；已有骨架实现。
- 屏幕组件只通过回调请求跳转，禁止直接改游戏状态。
