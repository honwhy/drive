# F12 运行环境、适配与性能（ENV / PF）

> 需求来源：`requirement.md` §3.12、第 5 章 ｜ 技术约定：`AGENTS.md` §7、§9 ｜ 状态：已实现待验证（见 [PROGRESS](PROGRESS.md)）

## 1. 目标

保证竖屏手机上的可玩性、离线可用与性能预算：三种尺寸不破版、切后台不耗电、断网可玩、驾驶中无长任务。

## 2. 需求范围

ENV-01 竖屏、ENV-02 横屏、ENV-03 切后台、ENV-04 触控、ENV-05 页面行为、ENV-06 声音（P1）、ENV-07 震动（P2）、ENV-08 离线、ENV-09 无网络依赖、ENV-10 兼容、ENV-11 可读性、ENV-12 低端降级。PF-01～10。

## 3. 适配基线

| 项目       | 数值                                |
| ---------- | ----------------------------------- |
| 基准机型   | iPhone 16 Pro，402 × 874 CSS，DPR 3 |
| 兼容尺寸   | 360×640、390×844、430×932           |
| 画布像素比 | 上限 2（804 × 1748）                |
| 安全区     | 顶部约 62 pt、底部约 34 pt          |
| 命中区     | ≥ 44×44 CSS px                      |
| 正文       | ≥ 12 px                             |

横屏只显示旋转提示，不提供横屏玩法；`orientation` 变化时暂停。

## 4. 离线与网络

- 生产环境注册 Service Worker，缓存应用外壳与同源静态资源。
- 导航 network-first，静态资源 cache-first；不缓存非 GET、非 2xx、跨域。
- 首次加载后断网重开：可进主菜单、玩已解锁关卡、保存进度。
- 运行期无任何外部请求；无请求失败导致的卡死。

## 5. 性能预算

| 项         | 目标                                |
| ---------- | ----------------------------------- |
| 首次可交互 | ≤ 3 s（4G）                         |
| 缓存后再开 | ≤ 1.5 s                             |
| 帧率       | 平均 ≥ 55 fps，1% 低帧 ≥ 30 fps     |
| 单帧停顿   | ≤ 100 ms                            |
| 输入延迟   | ≤ 100 ms                            |
| 资源体积   | ≤ 2 MB（gzip 后 JS+CSS ≤ 250 KB）   |
| 内存       | 10 分钟 ≤ 200 MB，30 分钟增长 ≤ 20% |
| 结算       | 结束到报告 ≤ 200 ms                 |
| 后台       | 停止循环，CPU 接近空闲              |

## 6. 实现约束

- 单 rAF 循环；暂停与页面隐藏时停止，不空转。
- HUD 文本 10 Hz；高频元素用 CSS 过渡，不逐帧重排。
- 画布离屏预渲染；热循环零分配；单帧绘制调用 ≤ 300。
- 低端设备可降级特效密度，但不得改变模拟频率与评分。
