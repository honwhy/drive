# F06 人工接管与交还（TAK）

> 需求来源：`requirement.md` §3.6、§4.6 ｜ 技术约定：`AGENTS.md` §6.5 ｜ 状态：已实现待验证（见 [PROGRESS](PROGRESS.md)）

## 1. 目标

在智驾能力不足时把控制权平滑交给玩家，并在条件允许时安全交还。接管必须即时、互斥、可统计，超时必须有安全兜底。

## 2. 需求范围

TAK-01 主动接管、TAK-02 系统请求、TAK-03 请求提示、TAK-04 超时停车、TAK-05 手动操控、TAK-06 交还条件、TAK-07 交还后状态、TAK-08 接管统计、TAK-09 不清空成绩、TAK-10 不暂停世界。

## 3. 流程

```text
自动驾驶
  ├─ 玩家点击接管 ──────────────→ 手动（≤ 200 ms）
  └─ 系统请求（原因 + 3 s 倒计时 + 持续制动）
        ├─ 玩家接管 → 手动
        └─ 超时 → 全力制动 → 安全停车 → 结算（未通过）
手动驾驶
  └─ 点击“恢复自动驾驶” → 检查交还条件
        ├─ 满足 → 跟车/巡航
        └─ 不满足 → 拒绝 + 提示原因
```

## 4. 请求与交还条件

**请求接管（任一）**

- 预测 3.5 s 内碰撞且制动/变道无法避免；
- 施工封道且无安全变道窗口；
- 前方静止障碍 TTC ≤ 3.5 s 且无绕行空间；
- 感知连续 1 s 无法支撑决策。

**交还自动驾驶（全部满足）**

- 前向距离 ≥ 1.5 × 目标跟车距离；
- 风险 ≤ 注意；
- 不在路口、不在变道过程中。

## 5. 交互与反馈

- 接管横幅：原因、倒计时数字、进度环、44×44 px 以上“立即接管”按钮。
- 接管瞬间清空自动控制输出，避免抢方向盘。
- 手动最高 120 km/h，不提供车道保持，边界与碰撞规则不变。
- 接管提示与手动期间世界持续运行，不得以暂停代替。

## 6. 统计

```ts
interface TakeoverEvent {
  id: number;
  startedAtS: number;
  endedAtS: number | null;
  reasonCode: string;
  requestedBySystem: boolean;
  outcome: 'manual' | 'timeoutStop' | 'collision';
}
```

统计进入报告：次数、每次时长、原因、是否系统请求（TAK-08）；接管按评分规则扣分，但不重置成绩（TAK-09）。

## 7. 模块与接口

- `src/game/decision/takeover.ts`：请求判定、倒计时、超时处理。
- 与状态机 `TAKEOVER_REQUEST | MANUAL` 双向迁移，迁移函数唯一。
- 倒计时基于固定 tick，不读系统时间。

## 8. 验收映射

AC-TAK-01～06、AC-FL-03～04。重点：200 ms 切换、3 s 超时、交还拒绝原因、统计零误差。
