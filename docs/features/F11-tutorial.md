# F11 教学与可视化（EDU）

> 需求来源：`requirement.md` §3.11 ｜ 技术约定：`AGENTS.md` §7.2 ｜ 状态：已实现待验证（见 [PROGRESS](PROGRESS.md)）

## 1. 目标

用最短路径让玩家理解“感知—决策—控制”：第 1 关分步教学、每关概念提示、失败原因解释、传感器图层开关。

## 2. 需求范围

EDU-01 首次教学、EDU-02 关卡说明、EDU-03 概念提示、EDU-04 失败提示、EDU-05 传感器图层（P1）、EDU-06 术语说明（P2）。

## 3. 教学流程（第 1 关）

```text
进入 → 说明（目标/失败条件）→ 开始
  → 步骤 1：按住加速，达到 20 km/h
  → 步骤 2：按住刹车，降到 5 km/h 以下
  → 步骤 3：左/右转向，保持 2 s
  → 完成 → 通过（需跑完 500 m）
```

- 每步有高亮控件与一行说明；可跳过，跳过不记为通过。
- 教学文案一次只出现一条，不遮挡道路与本车。

## 4. 概念卡

| 关卡 | 概念       | 关键句                           |
| ---- | ---------- | -------------------------------- |
| 2    | 感知       | 系统只“看见”射线与目标框内的东西 |
| 3    | 时距       | 距离 ÷ 速度，越大越安全          |
| 4    | AEB        | 来不及人工制动时的最后一道保险   |
| 5    | 变道窗口   | 前后都有足够空间才允许变道       |
| 6    | 路权与让行 | 红灯停、行人优先                 |

关卡说明在开局前展示，不剧透随机位置。

## 5. 传感器图层

- 开关粒度：射线 / 目标框 / 风险标记（P1）。
- 数据必须来自同一份感知快照（SEN-10）。
- 关闭图层不得影响感知与决策，只影响绘制。

## 6. 模块与接口

```ts
interface TutorialStep {
  id: string;
  text: string;
  highlight: 'accel' | 'brake' | 'steer';
  done: boolean;
}
interface Tutorial {
  readonly steps: readonly TutorialStep[];
  advance(input: ManualInput): void;
}
```

- `src/ui/tutorial.ts`：步骤机与 DOM 引导层。
- `src/render/overlay.ts`：传感器图层绘制，只读快照。
