# F02 局内画面与信息面板（HUD）

> 需求来源：`requirement.md` §3.2、§3.4 SEN-06 ｜ 技术约定：`AGENTS.md` ｜ 状态：已实现待验证（见 [PROGRESS](PROGRESS.md)）

## 1. 目标

用 Canvas 呈现世界，用 DOM 呈现可读信息：速度、前车距离、风险、驾驶模式、策略、进度、决策原因、接管提示与控件。信息必须“过程可见”，且不遮挡本车与前方 30 m 路面。

## 2. 需求范围

HUD-01 视角、HUD-02 道路呈现、HUD-03 核心信息、HUD-04 风险四级、HUD-05 决策状态、HUD-06 接管提示、HUD-07 手动控件、HUD-08 传感器可视化、HUD-09 关键事件提示、HUD-10 布局约束、HUD-11 单位格式、HUD-12 进度。

## 3. 布局

```text
┌──────────────────────────┐
│ 顶部：关卡名 / 策略 / 暂停 │  安全区内边距
│ 指标条：速度 距离 风险 模式 │
│                          │
│        Canvas 世界        │  本车固定在 70% 高度
│   （前方 30 m 不遮挡）     │
│                          │
│ 决策状态条：跟车 · 原因     │
│ 控件区：接管 / 四向按钮     │
└──────────────────────────┘
```

- 接管横幅出现在指标条下方，不覆盖本车与前方路面。
- 控件最小命中区 44×44 px；手动模式四键，自动模式一个“接管”按钮。
- HUD 文本 10 Hz 刷新；风险色块与速度条用 CSS 过渡，不逐帧写 DOM。

## 4. 数据与格式

| 信息       | 来源                | 格式                   |
| ---------- | ------------------- | ---------------------- |
| 速度       | 本车状态            | 整数 km/h              |
| 前车距离   | 感知 SEN-01         | 1 位小数 m             |
| 时距 / TTC | 感知                | 1 位小数 s             |
| 风险       | SEN-06 四级         | 颜色 + 文字 + 图标     |
| 模式       | 状态机              | 自动 / 手动 / 请求接管 |
| 进度       | 世界位置 / 关卡长度 | 进度条 + 剩余距离      |

超速、压线、闯红灯、AEB、变道打灯等事件以短时提示条展示，3 s 自动消失，不堆叠超过 2 条。

## 5. 模块与接口

```ts
interface HudModel {
  speedKmh: number;
  leadDistanceM: number | null;
  risk: 'safe' | 'caution' | 'warning' | 'danger';
  mode: 'auto' | 'manual' | 'takeoverRequest';
  policyName: string;
  decision: { state: string; reasonCode: string };
  progress: { travelledM: number; totalM: number };
}
interface Hud {
  update(model: HudModel): void;
}
```

- `src/ui/hud.ts` 只读模型，不读世界对象。
- 文案全部来自 `src/ui/strings.ts`；原因码到文案的映射单独维护。

## 6. 验收映射
