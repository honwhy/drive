# F08 关卡与场景（LVL）

> 需求来源：`requirement.md` §3.8、§3.9 LVL 相关 ｜ 技术约定：`AGENTS.md` §6.3 ｜ 状态：已实现待验证（见 [PROGRESS](PROGRESS.md)）

## 1. 目标

提供 7 个递进关卡与可复现的随机场景生成：确定性种子、公平生成约束、事件库与通过条件。

## 2. 需求范围

LVL-01 关卡结构、LVL-02 第 1 关教学、LVL-03 自动起步、LVL-04 解锁记录、LVL-05 重玩、LVL-06 公平性、LVL-07 道路几何、LVL-08 交通元素、LVL-09 事件库、LVL-10 完成判定、LVL-11 随机挑战、LVL-12 种子展示（P2）。

## 3. 关卡表

| 关卡 | 名称         | 场景                                                 | 通过条件                                  |
| ---- | ------------ | ---------------------------------------------------- | ----------------------------------------- |
| 1    | 汽车会动     | 500 m 双车道直道，无交通，手动教学                   | 完成 500 m、未越界、完成 3 步教学         |
| 2    | 汽车会看     | 600 m 直道，3 个静止障碍/锥桶                        | 完成赛程、零碰撞                          |
| 3    | 汽车会跟车   | 800 m，相邻车道连续车流无窗口，前车 50～80 km/h 变速 | 完成赛程、零碰撞、时距 ≥ 1.0 s 占比 ≥ 80% |
| 4    | 汽车会刹车   | 800 m，前车 3 次随机急刹                             | 完成赛程、零碰撞                          |
| 5    | 汽车会变道   | 1 km，本车道 40 km/h 慢车，至少 1 次安全窗口         | 完成赛程、≥ 1 次成功变道、零碰撞          |
| 6    | 汽车会过路口 | 1 km，2 个信号灯路口、行人、横向车流                 | 完成赛程、零碰撞、零闯红灯、让行          |
| 7    | 智驾挑战     | 3 km，随机 ≥ 5 事件，含弯道                          | 完成赛程、零碰撞、总分 ≥ 60               |

所有关卡通过均需综合评分 ≥ 60。

## 4. 公平生成

- 目标不得在本车前方 `max(30 m, 2 s 行驶距离)` 或后方 15 m 内突现。
- 旁车加塞提前 `max(15 m, 1.5 s 行驶距离)` 开始，横向接近可见。
- 行人进入车道前可见 ≥ 2 s。
- 施工封道提供安全窗口，或提前 ≥ 3 s 请求接管。
- 信号灯不出现无法舒适停车的绿转黄；关键事件间隔 ≥ 8 s，同时最多 1 个。

## 5. 生成器接口

```ts
interface ScenarioConfig {
  levelId: number;
  seed: number;
  lengthM: number;
  laneCount: number;
  events: EventSpec[];
  road: RoadGeometry;
  startSpeedKmh: number;
}
function generateScenario(levelId: number, seed: number): ScenarioConfig;
```

- 随机只用 `createRng(seed)`，禁止 `Math.random()`。
- 相同 seed + 相同输入 → 相同事件序列、轨迹与评分。
- 第 7 关每局 ≥ 5 个事件，覆盖 ≥ 4 类，且满足公平约束。

## 6. 测试要点

| 用例        | 期望                               |
| ----------- | ---------------------------------- |
| 可复现      | 同 seed 生成结果完全一致（深比较） |
| 公平性      | 1 万次生成无“突现”与“必然碰撞”     |
| 事件间隔    | 关键事件间隔 ≥ 8 s                 |
| 第 5 关可通 | 至少 1 次安全变道窗口              |
| 第 7 关覆盖 | 10 局均 ≥ 5 事件、≥ 4 类           |
