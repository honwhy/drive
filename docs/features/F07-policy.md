# F07 驾驶策略（POL）

> 需求来源：`requirement.md` §3.7 ｜ 技术约定：`AGENTS.md` §6.6 ｜ 状态：已实现待验证（见 [PROGRESS](PROGRESS.md)）

## 1. 目标

用一套参数化的策略预设改变智驾“性格”：跟车距离、目标车速、反应时间、变道积极性。策略必须真实影响行为，而不是只改文案。

## 2. 需求范围

POL-01 三种预设、POL-02 参数生效、POL-03 对局锁定、POL-04 展示、POL-05 自定义（P1）、POL-06 对比（P2）。

## 3. 参数表

| 参数                   | 保守            | 普通            | 激进                |
| ---------------------- | --------------- | --------------- | ------------------- |
| 期望跟车时距           | 2.2 s           | 1.6 s           | 1.0 s               |
| 最高车速               | 90 km/h         | 110 km/h        | 120 km/h            |
| 决策反应时间           | 0.6 s           | 0.4 s           | 0.25 s              |
| 变道触发：前车慢于期望 | 5 m/s，持续 3 s | 3 m/s，持续 2 s | 1.5 m/s，持续 1.5 s |
| 变道前方最小净距       | 20 m            | 15 m            | 10 m                |
| 后方来车最小到达时间   | 5 s             | 3.5 s           | 2.5 s               |

要求：相对关系固定；最高车速还须取道路/弯道限速的较小值（AI-10）。

## 4. 行为影响点

- 目标跟车距离 = max(5 m, v × 时距)。
- 目标车速 = min(策略最高车速, 道路限速, 弯道限速)。
- 变道触发阈值与安全窗口。
- 决策反应时间以固定 tick 折算（如 0.4 s ≈ 6 个决策 tick），不得用真实时间。

## 5. 模块与接口

```ts
interface Policy {
  id: 'conservative' | 'normal' | 'aggressive' | 'custom';
  name: string;
  timeHeadwayS: number;
  maxSpeedKmh: number;
  reactionTimeS: number;
  laneChange: { slowDeltaMps: number; holdS: number; frontGapM: number; rearArrivalS: number };
}
```

- `src/config/policies.ts`：`readonly` 常量，运行时不可修改；自定义策略生成新对象，不改共享配置。
- 第 1 关不参与策略选择，展示为“手动教学”。

## 6. 测试要点

| 用例       | 期望                                                       |
| ---------- | ---------------------------------------------------------- |
