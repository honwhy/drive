# 按钮点击音 `sfx-ui-click.m4a`

> **项目简报（生成素材前必读）**
> 《AI 智驾模拟器》是手机竖屏、单人、可离线游玩的智驾观察小游戏：玩家观察 AI 完成感知、决策与控制，必要时接管，结束后查看评分报告。
> 画布基准机型 iPhone 16 Pro（402×874 CSS px）；界面简体中文；全部素材本地化、离线可用、无外链。

| 项            | 要求                                          |
| ------------- | --------------------------------------------- |
| 文件路径      | `public/media/audio/sfx-ui-click.m4a`        |
| 用途          | 所有按钮点击、卡片选择的统一反馈音            |
| 触发          | 主菜单、暂停、设置、结算按钮点击时各播放 1 次 |
| 时长          | 0.08 ～ 0.12 s                                |
| 采样率 / 帧长 | 48 000 Hz / AAC 1024 samples（≈ 21.3 ms）     |
| 声道          | 单声道                                        |
| 编码          | AAC-LC，96 kbps VBR，MP4 容器 `.m4a`          |
| 响度          | −16 LUFS，真峰值 ≤ −1 dBTP                    |
| 循环          | 否                                            |
| 体积          | ≤ 12 KB                                       |
| 关联需求      | ENV-06、NAV-01、NAV-07                        |

## 声音描述

- 合成器短促“哒”声：中高频（1.5～3 kHz）为主，衰减时间 60～80 ms。
- 音头清晰、无混响尾巴，连续快速点击时不叠成噪音。
- 情绪中性、机械感，不使用鼓点或旋律。

## 禁止事项

- 不得使用真人语音、真实机械录音、版权音效库片段。
- 不得包含静音头（首帧即起音），避免点击延迟感。
- 不得削波或超过 −1 dBTP。
