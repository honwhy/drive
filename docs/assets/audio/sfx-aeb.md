# AEB 触发音 `sfx-aeb.m4a`

> **项目简报（生成素材前必读）**
> 《AI 智驾模拟器》是手机竖屏、单人、可离线游玩的智驾观察小游戏：玩家观察 AI 完成感知、决策与控制，必要时接管，结束后查看评分报告。
> 画布基准机型 iPhone 16 Pro（402×874 CSS px）；界面简体中文；全部素材本地化、离线可用、无外链。

| 项            | 要求                                        |
| ------------- | ------------------------------------------- |
| 文件路径      | `public/media/audio/sfx-aeb.m4a`           |
| 用途          | 自动紧急制动触发提示                        |
| 触发          | AEB 判定成立瞬间播放 1 次，单次触发内不重复 |
| 时长          | 0.6 ～ 0.8 s                                |
| 采样率 / 帧长 | 48 000 Hz / AAC 1024 samples（≈ 21.3 ms）   |
| 声道          | 单声道                                      |
| 编码          | AAC-LC，96 kbps VBR，MP4 容器 `.m4a`        |
| 响度          | −14 LUFS，真峰值 ≤ −1 dBTP                  |
| 循环          | 否                                          |
| 体积          | ≤ 24 KB                                     |
| 关联需求      | AI-04、HUD-09、ENV-06                       |

## 声音描述

- 由“短促双脉冲 + 低频下坠”构成：两声 1000 Hz 脉冲（各 60 ms），随后 200→80 Hz 的低频扫频 300 ms，模拟制动介入。
- 起音必须与 AEB 状态切换同帧，不得有 20 ms 以上延迟。
- 情绪：紧急但克制；音量不得高于接管请求音。
- 需要与 `sfx-collision.m4a` 区分：AEB 为电子提示，碰撞为低沉闷响。

## 禁止事项

- 不得使用真实刹车尖啸、轮胎摩擦录音。
- 不得使用人声。
- 不得拖尾超过 0.8 s（会与碰撞音重叠）。
