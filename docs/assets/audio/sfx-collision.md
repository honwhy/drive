# 碰撞音 `sfx-collision.m4a`

> **项目简报（生成素材前必读）**
> 《AI 智驾模拟器》是手机竖屏、单人、可离线游玩的智驾观察小游戏：玩家观察 AI 完成感知、决策与控制，必要时接管，结束后查看评分报告。
> 画布基准机型 iPhone 16 Pro（402×874 CSS px）；界面简体中文；全部素材本地化、离线可用、无外链。

| 项            | 要求                                      |
| ------------- | ----------------------------------------- |
| 文件路径      | `public/media/audio/sfx-collision.m4a`   |
| 用途          | 碰撞发生时的结束反馈音                    |
| 触发          | 碰撞判定成立、世界冻结时播放 1 次         |
| 时长          | 0.9 ～ 1.2 s                              |
| 采样率 / 帧长 | 48 000 Hz / AAC 1024 samples（≈ 21.3 ms） |
| 声道          | 单声道                                    |
| 编码          | AAC-LC，96 kbps VBR，MP4 容器 `.m4a`      |
| 响度          | −13 LUFS，真峰值 ≤ −1 dBTP                |
| 循环          | 否                                        |
| 体积          | ≤ 28 KB                                   |
| 关联需求      | VEH-05、SCR-06、ENV-06                    |

## 声音描述

- 低沉闷响（60～120 Hz，衰减 600 ms）+ 短促金属碎裂质感（高频噪声 150 ms，快速衰减）。
- 冲击感明确但不引发不适；不得使用爆炸、枪声等夸张音效。
- 尾部自然衰减到静音，不留循环点。
- 与 `sfx-aeb.m4a` 音色区分：碰撞为低频为主，AEB 为电子高频。

## 禁止事项

- 不得使用真实事故录音、玻璃破碎实录音。
- 不得包含人声惊呼。
- 不得削波；响度不得超过 −13 LUFS。
