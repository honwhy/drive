# 接管请求音 `sfx-takeover-alert.m4a`

> **项目简报（生成素材前必读）**
> 《AI 智驾模拟器》是手机竖屏、单人、可离线游玩的智驾观察小游戏：玩家观察 AI 完成感知、决策与控制，必要时接管，结束后查看评分报告。
> 画布基准机型 iPhone 16 Pro（402×874 CSS px）；界面简体中文；全部素材本地化、离线可用、无外链。

| 项            | 要求                                             |
| ------------- | ------------------------------------------------ |
| 文件路径      | `public/media/audio/sfx-takeover-alert.m4a`     |
| 用途          | 系统请求接管时的循环警示音                       |
| 触发          | 显示接管横幅时开始循环，接管完成或安全停车后停止 |
| 时长          | 1.2 s（循环单元）                                |
| 采样率 / 帧长 | 48 000 Hz / AAC 1024 samples（≈ 21.3 ms）        |
| 声道          | 单声道                                           |
| 编码          | AAC-LC，96 kbps VBR，MP4 容器 `.m4a`             |
| 响度          | −14 LUFS，真峰值 ≤ −1 dBTP                       |
| 循环          | 是，循环点误差 ≤ 5 ms，首尾零交叉                |
| 体积          | ≤ 32 KB                                          |
| 关联需求      | TAK-02、TAK-03、ENV-06                           |

## 声音描述

- 两音交替的紧迫提示（如 660 Hz / 880 Hz），每音 180 ms，中间静音 120 ms，整体节奏明显但不过度尖锐。
- 循环播放时不得出现“咔哒”接缝；不得有渐入渐出导致的音量呼吸。
- 情绪：提醒而非恐吓；不得使用警报器长鸣。
- 与 `sfx-warning.m4a`（危险等级）音色需可区分：接管音为双音交替，警告音为单音双击。

## 禁止事项

- 不得使用真人语音“请接管”。
- 不得使用真实车辆告警录音。
- 不得在循环单元内包含超过 200 ms 的静音。
