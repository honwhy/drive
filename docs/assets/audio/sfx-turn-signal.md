# 转向灯音 `sfx-turn-signal.m4a`

> **项目简报（生成素材前必读）**
> 《AI 智驾模拟器》是手机竖屏、单人、可离线游玩的智驾观察小游戏：玩家观察 AI 完成感知、决策与控制，必要时接管，结束后查看评分报告。
> 画布基准机型 iPhone 16 Pro（402×874 CSS px）；界面简体中文；全部素材本地化、离线可用、无外链。

| 项            | 要求                                      |
| ------------- | ----------------------------------------- |
| 文件路径      | `public/media/audio/sfx-turn-signal.m4a` |
| 用途          | 自动变道打灯期间的节奏提示                |
| 触发          | 转向灯亮起时循环，变道完成或中止后停止    |
| 时长          | 0.6 s（循环单元，含 1 次“滴”）            |
| 采样率 / 帧长 | 48 000 Hz / AAC 1024 samples（≈ 21.3 ms） |
| 声道          | 单声道                                    |
| 编码          | AAC-LC，96 kbps VBR，MP4 容器 `.m4a`      |
| 响度          | −18 LUFS，真峰值 ≤ −1 dBTP                |
| 循环          | 是，循环点误差 ≤ 5 ms                     |
| 体积          | ≤ 16 KB                                   |
| 关联需求      | HUD-09、AI-05、ENV-06                     |

## 声音描述

- 单声“滴”：800 Hz、60 ms、快速衰减，后接 540 ms 静音，形成 0.6 s 节奏。
- 音量明显低于接管与 AEB 提示音，避免长时间变道时干扰。
- 循环接缝无声爆；静音段不得被截断。

## 禁止事项

- 不得使用真实车辆继电器咔哒录音以外的机械噪声。
- 不得包含人声“左转/右转”。
- 不得设计成持续长鸣。
