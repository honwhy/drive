# 结算音 `sfx-report.m4a`

> **项目简报（生成素材前必读）**
> 《AI 智驾模拟器》是手机竖屏、单人、可离线游玩的智驾观察小游戏：玩家观察 AI 完成感知、决策与控制，必要时接管，结束后查看评分报告。
> 画布基准机型 iPhone 16 Pro（402×874 CSS px）；界面简体中文；全部素材本地化、离线可用、无外链。

| 项            | 要求                                      |
| ------------- | ----------------------------------------- |
| 文件路径      | `public/media/audio/sfx-report.m4a`      |
| 用途          | 结算报告出现时的结果反馈音                |
| 触发          | 结算页首次渲染完成时播放 1 次             |
| 时长          | 1.6 ～ 2.5 s                              |
| 采样率 / 帧长 | 48 000 Hz / AAC 1024 samples（≈ 21.3 ms） |
| 声道          | 单声道                                    |
| 编码          | AAC-LC，96 kbps VBR，MP4 容器 `.m4a`      |
| 响度          | −16 LUFS，真峰值 ≤ −1 dBTP                |
| 循环          | 否                                        |
| 体积          | ≤ 48 KB                                   |
| 关联需求      | SCR-06、ENV-06、NAV-08                    |

## 声音描述

- 三段上行和弦（如 C–E–G 的柔和正弦叠加），每段 400 ms，尾部 600 ms 自然衰减。
- 情绪中性偏正向，不区分通过/未通过；未通过时由界面文案说明原因，音效不得表达“胜利”或“失败”的强情绪。
- 不得使用真实乐器采样；使用合成音色。
- 起音与结算页出现同步，延迟 ≤ 50 ms。

## 禁止事项

- 不得使用欢呼、掌声、喇叭、人声。
- 不得包含刺耳高频或过度混响。
- 不得作为背景音乐循环。
