# 危险提示音 `sfx-warning.m4a`

> **项目简报（生成素材前必读）**
> 《AI 智驾模拟器》是手机竖屏、单人、可离线游玩的智驾观察小游戏：玩家观察 AI 完成感知、决策与控制，必要时接管，结束后查看评分报告。
> 画布基准机型 iPhone 16 Pro（402×874 CSS px）；界面简体中文；全部素材本地化、离线可用、无外链。

| 项            | 要求                                                        |
| ------------- | ----------------------------------------------------------- |
| 文件路径      | `public/media/audio/sfx-warning.m4a`                       |
| 用途          | 风险等级升到“危险”时的短提示                                |
| 触发          | 风险由“警告”升至“危险”时播放 1 次；同一次危险持续期内不重复 |
| 时长          | 0.4 ～ 0.6 s                                                |
| 采样率 / 帧长 | 48 000 Hz / AAC 1024 samples（≈ 21.3 ms）                   |
| 声道          | 单声道                                                      |
| 编码          | AAC-LC，96 kbps VBR，MP4 容器 `.m4a`                        |
| 响度          | −16 LUFS，真峰值 ≤ −1 dBTP                                  |
| 循环          | 否                                                          |
| 体积          | ≤ 14 KB                                                     |
| 关联需求      | HUD-04、SEN-06、ENV-06                                      |

## 声音描述

- 单音双击：1000 Hz、各 70 ms、间隔 90 ms，快速衰减。
- 与接管音（双音交替）音高不同、节奏更短，避免混淆。
- 情绪：提醒，不制造恐慌；音量低于接管请求音。

## 禁止事项

- 不得使用人声、警报器长鸣。
- 不得循环播放。
- 不得在风险等级未变化时重复触发。
