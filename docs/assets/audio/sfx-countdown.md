# 倒计时音 `sfx-countdown.m4a`

> **项目简报（生成素材前必读）**
> 《AI 智驾模拟器》是手机竖屏、单人、可离线游玩的智驾观察小游戏：玩家观察 AI 完成感知、决策与控制，必要时接管，结束后查看评分报告。
> 画布基准机型 iPhone 16 Pro（402×874 CSS px）；界面简体中文；全部素材本地化、离线可用、无外链。

| 项            | 要求                                           |
| ------------- | ---------------------------------------------- |
| 文件路径      | `public/media/audio/sfx-countdown.m4a`        |
| 用途          | 开局 3-2-1 倒计时与恢复前 1 s 倒计时           |
| 触发          | 关卡开始倒计时；暂停恢复倒计时（只播最后一拍） |
| 时长          | 2.4 ～ 3.0 s                                   |
| 采样率 / 帧长 | 48 000 Hz / AAC 1024 samples（≈ 21.3 ms）      |
| 声道          | 单声道                                         |

| 响度          | −16 LUFS，真峰值 ≤ −1 dBTP                     |
| 循环          | 否                                             |
| 体积          | ≤ 40 KB                                        |
| 关联需求      | NAV-05、NAV-06                                 |

## 声音描述

- 结构：3 声等间隔提示（间隔 0.7 s，每声 80 ms），第 4 声为更高音“出发”音，持续 200 ms。
- 音高：前三声 880 Hz 方波/三角波柔和版，最后一声 1320 Hz，形成明确的上行结束感。
- 节奏稳定、间隔误差 ≤ 10 ms；不得使用人声报数（“三、二、一”）。
- 恢复倒计时只使用最后一拍，需能从文件中按时间点截取（最后一拍起始时间写入 `balance.ts` 配置，不写死在代码）。

## 禁止事项

- 不得使用真实发令枪、汽车鸣笛、人声。
- 不得在文件头尾添加静音。
- 不得使用刺耳的高频方波（听感疲劳）。
