## 画面要素

1. 正俯视、车头朝上，车身比轿车宽约 12%，轮廓更方，车窗面积更大。
2. 车身主色墨绿灰 `#3F5B52`，车顶浅灰绿 `#BFD3C8`；与本车蓝、轿车灰蓝都要区分得开。

4. 车尾双红尾灯 `#E5484D`，车头浅色灯带；无投影、无文字。
