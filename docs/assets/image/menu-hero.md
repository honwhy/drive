## 画面要素

1. 竖构图夜景/黄昏道路：一条三车道公路从画面下方向上方延伸，消失点位于画面上方 1/3。
2. 画面上方 25% 为低对比暗区（`#0B1220` → `#16233A` 渐变），供标题与徽标压字，不得有高对比细节。
3. 画面下方 35% 为深色渐隐区，供按钮组使用；中部可放一辆代表本车的蓝色车辆（车头朝上，远处有 1～2 辆灰色交通车）。
4. 道路右侧可有橙色路灯/施工灯点缀，作为主色呼应，面积不超过画面 8%。
5. 安全区：顶部 62 pt、底部 34 pt 内不得出现关键视觉元素。
6. 需兼容 360×640 与 430×932 的 cover 裁切：主体（车、道路消失点）保持在中央 70% 水平范围内。

## 禁止事项

- 不得包含任何文字、数字、Logo、真实品牌。
- 不得使用真人照片、写实 3D 渲染、强镜头光晕。
- 不得使用高饱和红绿对比（色盲友好）。
- 不得依赖外部图片或纹理拼接。
