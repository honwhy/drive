## 画面要素

1. 正俯视、车头朝上的紧凑型轿车，长宽比约 2.5:1，轮廓圆角半径约 6 px（2 倍图）。
2. 车身使用品牌蓝 `#2F6FDC`，车顶/座舱用更亮的蓝灰 `#B9D4FF`，前挡风玻璃位于上方 1/3。
3. 车头两侧各有一盏暖黄日行灯 `#FFD166`，车尾两侧为红色尾灯 `#E5484D`；灯光不发光溢出到透明区。
4. 车轮为深灰 `#1B2430` 矩形，压在车身两侧，不得突出车身轮廓。
5. 需在 32×80 CSS px 下可辨认“车头朝上”，不依赖文字或箭头。
6. 预留状态叠加空间：转向灯、刹车灯由渲染层动态绘制，素材不要画死常亮灯。

## 禁止事项

- 不得使用真实汽车品牌、车标、车牌。
- 不得绘制阴影投到车身之外（阴影由渲染层统一处理）。
- 不得包含文字、数字、水印。
- 不得使用渐变高光导致小尺寸下糊成一片。
