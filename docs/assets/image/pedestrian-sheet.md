## 画面要素

1. **俯视角**（从上往下看），不是正面立绘；能看到头顶与肩部，身体略向前倾。
2. 帧 0 与帧 1 为左右脚交替的迈步姿态，两帧差异清晰但不夸张，循环播放自然。
3. 衣着使用橙色系 `#F2994A` 与浅灰 `#C9D4DE`，与道路、车辆形成对比；不得使用与风险红相同的纯红作为主色（风险色留给 HUD）。
4. 头部圆形，深色头发；可带 1 个高对比配饰（如浅色背包）提升可读性，但不得遮挡轮廓。
5. 透明背景，两帧之间不重叠、不留分隔线；每帧内容居中对齐，脚底基线一致。
6. 在 28×48 CSS px 下仍能辨认“人”而不是色块。

## 禁止事项

- 不得出现真实人脸、照片、文字。
- 不得使用与锥桶橙完全一致的颜色（锥桶为 `#F2C94C` 系）。
- 不得绘制影子到帧外。
