## 画面要素

1. 深灰沥青底 `#2A3542`，叠加低对比细颗粒噪点（明度差 ≤ 6%），颗粒直径 1～2 px（2 倍图）。
2. **四边可无缝平铺**：左接右、上接下不得出现接缝、亮线或重复图案感。
3. 可含极少量浅灰裂纹（≤ 3 条、宽度 1 px、不连续），但不得形成方向性强的纹理。
4. 不得包含车道线、箭头、文字、油渍等语义元素（这些由渲染层绘制）。
5. 整体明度必须低于车辆与警示色，保证前景可读。

## 禁止事项

- 不得使用照片纹理或外部贴图。
- 不得出现明显重复的点阵/网格。
- 不得使用高饱和颜色。
