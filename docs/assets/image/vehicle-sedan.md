## 画面要素

1. 正俯视、车头朝上的紧凑型轿车，轮廓与本车同构但更短，便于玩家区分“自己”和“别人”。
2. 车身主色用中性灰蓝 `#56657A`，车顶浅灰 `#C9D4DE`；**不得使用本车蓝**，避免混淆。
3. 车尾有 2 个红色尾灯块 `#E5484D`，车头为浅色灯带；制动时由渲染层额外叠加高亮，素材不画常亮刹车灯。
4. 车轮深灰 `#1B2430`，不突出车身；整体无投影。
5. 在 30×72 CSS px 下能看出“车尾朝下、车头朝上”。

## 禁止事项

- 不得使用真实品牌、车标、车牌、文字。
- 不得使用与本车相同的蓝色主色或相同轮廓比例。
- 不得绘制转向灯常亮（转向灯由渲染层叠加闪烁）。
