## 画面要素

1. 主体：正俯视的蓝色车辆剪影（车头朝上），上方叠加 3 条半透明扇形感知射线，体现“感知 + 驾驶”。
2. 背景：深蓝渐变 `#0B1220` → `#1B3358`；车辆用 `#2F6FDC`，射线用 `#F2994A` 低透明度（≤ 35%）。
3. 图形整体居中，视觉重心略偏下；不使用文字、字母缩写。
4. `app-icon-512.png`：允许图形靠近边缘（系统会裁圆角），主体占画布 72%。
5. `app-icon-maskable-512.png`：**必须**在中心 80% 安全圆内放置主体（外圈 20% 可被裁切），背景铺满整张画布，不得使用透明。

## 禁止事项

- 不得使用真实车标、品牌、真人照片。
- 不得包含中英文文字、数字。
- 不得使用透明背景或描边贴边。
- 两个文件不得使用不同构图（便于替换时保持一致）。
